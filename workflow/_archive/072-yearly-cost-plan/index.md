Project spending year by year so the household can plan around the years when big fixed costs (mortgage, tuition, baby costs) end or drop.

## User Stories

- As a user, I want to set an end year (or a step-down) on a fixed cost like the mortgage or tuition so that the plan reflects when it stops.
- As a user, I want a year-by-year view of projected spending so that I can see which year costs drop and by how much.
- As a user, I want to see the freed-up amount each year so that I can plan what to do with it.

## Success

- A yearly projection shows expected spending per year, with each fixed cost's end or step-down reflected.
- The years where costs drop are easy to spot.

### Out of Scope

- Deciding what to cut today (see the sibling cost-cutting review feature).

## Plan

To be shaped at ideation. Open questions: where end dates live (on recurring expenses vs. a separate plan), how far ahead to project, whether to account for inflation.
